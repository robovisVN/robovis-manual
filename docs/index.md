# Tài liệu hướng dẫn Robovis

Bắt đầu với kiến thức nền nếu bạn mới học, hoặc chọn dòng robot để xem hướng dẫn cài đặt, lập trình và sử dụng.

## Mới bắt đầu?

Chưa biết Ubuntu, Terminal hoặc cách tìm thư mục? Học từng bước trong **Ubuntu cơ bản**, rồi quay lại tài liệu robot khi đã sẵn sàng.
