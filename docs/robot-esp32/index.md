# Tổng quan Robot ESP32

Đây là trang mở đầu của nhóm **Robot ESP32**. Cấu trúc đề xuất dựa trên danh mục hiện tại:

1. Tổng quan
2. Chuẩn bị môi trường lập trình
3. Điều khiển LED
4. Điều khiển động cơ Servo
5. Điều khiển động cơ DC với L298N
6. Đọc cảm biến HC-SR04
