# Tài liệu sản phẩm

Chọn đúng dòng robot để mở hướng dẫn. Mỗi sản phẩm có danh sách bài riêng, từ chuẩn bị đến sử dụng và xử lý lỗi.

| Sản phẩm | Nội dung | Mở tài liệu |
| --- | --- | --- |
| Robot Arduino | Giới thiệu, chuẩn bị linh kiện, lắp ráp và lập trình | [Bắt đầu](../robot-arduino/01-gioi-thieu.md) |
| Robot ESP32 | Trang tổng quan và định hướng nội dung | [Tổng quan](../robot-esp32/index.md) |
| Robot ESP32 Camera | Arduino IDE, nạp chương trình, điều khiển và YOLO | [Bắt đầu](../robot-esp32-camera/01-bat-dau/01-tong-quan.md) |
| Robot ESP32 LiDAR | Ubuntu, ROS 2, chạy thử, SLAM và Nav2 | [Bắt đầu](../robot-esp32-lidar/index.md) |

Nếu chưa quen Ubuntu, xem [Kiến thức nền](../kien-thuc-nen/index.md) trước khi làm các bài ROS 2. Các gói tài liệu được tập hợp tại [Tải xuống](../tai-xuong/index.md).
