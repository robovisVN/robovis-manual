# Bài 6: Đọc tín hiệu HC-SR04 với Arduino Nano

## Mục tiêu bài học

Sau bài này, bạn có thể:

- Phát xung Trig và đo thời gian Echo.
- Tính khoảng cách từ thời gian âm đi/về.
- Phân biệt không có Echo với vật ở khoảng cách 0 cm.

**Trước khi bắt đầu:** Điều khiển motor — [mở bài trước](05-dong-co.md). Mỗi mã chạy thử là một sketch độc lập; Upload sẽ thay chương trình đang chạy. Giữ bản mã robot gốc để nạp lại sau khi học.

## 1. Nguyên lý và kiến thức cần biết

HC-SR04 phát siêu âm khi Trig nhận xung kích hoạt, Echo HIGH trong khoảng thời gian tương ứng. Công thức gần đúng: khoảng cách cm = thời gian µs / 58. Âm đi từ cảm biến tới vật rồi quay lại nên phải chia cho hai. Bài dùng chu kỳ đo 100 ms và timeout 25 ms. Xem [datasheet HC-SR04](https://cdn.sparkfun.com/datasheets/Sensors/Proximity/HCSR04.pdf).

## 2. Chuẩn bị, bảng chân và đấu nối

| HC-SR04 | Arduino Nano |
| --- | --- |
| Trig | A0 |
| Echo | A1 |
| VCC | Nguồn phù hợp HC-SR04, thường 5 V với module chuẩn |
| GND | GND chung |

Ngắt nguồn motor. Tháo đường IN1/IN2 của driver khỏi D0/D1 trong các bài dùng Serial. Chỉ ngắt nguồn động cơ chưa loại bỏ xung đột tín hiệu trên D0/D1.

Nano classic dùng logic 5 V; kiểm tra đúng loại cảm biến trước khi nối.

## 3. Mã chạy thử hoàn chỉnh

Tạo sketch riêng có tên thư mục trùng tên tệp `.ino`, chép toàn bộ mã sau, chọn đúng board/COM rồi Verify và Upload:

```cpp
const int TRIG = A0;
const int ECHO = A1;

void setup() {
  pinMode(TRIG, OUTPUT);
  digitalWrite(TRIG, LOW);
  pinMode(ECHO, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long us = pulseIn(ECHO, HIGH, 25000UL);
  if (us == 0) {
    Serial.println("Khong co Echo hop le");
  } else {
    float cm = us / 58.0f;
    Serial.print("Khoang cach cm: ");
    Serial.println(cm);
  }
  delay(100);
}
```

## 4. Giải thích chương trình

`delayMicroseconds(10)` tạo xung Trig. pulseIn() trả thời gian hoặc 0 khi hết timeout; không diễn giải 0 thành vật sát cảm biến. Số đo chịu ảnh hưởng góc, bề mặt và nhiệt độ. pulseIn() là hàm chờ, nên khi kết hợp PID/Wi-Fi cần xem ảnh hưởng thời gian chờ.

## 5. Chạy thử và kết quả mong đợi

Mở Monitor 9600 baud, đặt tấm phẳng trước cảm biến ở khoảng 15, 30, 50 cm, ghi số đo và so với thước. Vật mềm hoặc nghiêng có thể cho Echo kém. Đây là sketch đo riêng; motor chưa được điều khiển.

## 6. Lỗi thường gặp

| Hiện tượng | Cách kiểm tra |
| --- | --- |
| Không Echo | Trig/Echo, GND, nguồn, góc/bề mặt vật |
| Số đo nhảy | Vật nghiêng, rung, nhiễu nguồn, chu kỳ đo |
| ESP32 không ổn định | Mức Echo, không nối 5 V trực tiếp vào GPIO |

## 7. Bài tập thực hành

1. In “Vat gan” khi phép đo hợp lệ dưới 20 cm.
2. Tính trung bình ba mẫu hợp lệ, không gộp timeout thành 0 cm.
3. Khi kết hợp motor, viết quyết định dừng nếu không có phép đo hợp lệ; kiểm tra trên bánh kê trước.

**Điều kiện học tiếp:** thực hiện được mục tiêu của bài và giải thích được kết quả quan sát.
