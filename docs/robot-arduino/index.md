# Tổng quan Robot Arduino

Đây là trang mở đầu của nhóm **Robot Arduino**. Khi chuyển nội dung thật, các bài hiện có nên được sắp xếp theo thứ tự:

1. Tổng quan
2. Cài đặt Arduino IDE
3. Điều khiển LED
4. Điều khiển động cơ Servo
5. Điều khiển động cơ DC với L298N

!!! note "Trạng thái bản mẫu"
    Trang này mới minh họa cấu trúc. Nội dung hoàn chỉnh đầu tiên nằm tại **Robot ESP32 LiDAR → Tổng quan**.
