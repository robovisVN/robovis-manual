# Bắt đầu với Robot Arduino Nano

Lộ trình dành cho người chưa từng lập trình: cài công cụ, nạp chương trình, đọc nút nhấn và thử servo trước khi áp dụng vào robot.

**Phạm vi:** Nano classic **ATmega328P, logic 5 V**. Nano Every, Nano ESP32 và Nano 33 là các bo khác. Sơ đồ thực hành dùng linh kiện rời, không quy định chân của robot Robovis.
